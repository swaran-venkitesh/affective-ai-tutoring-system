# Affective Intelligence-Driven Personalized AI Tutoring System

## Overview
This repository contains an academic research implementation of an affective-intelligence-driven personalized AI tutoring system developed during a research internship at Newcastle University in Singapore under the guidance of Prof. Anurag Sharma.

The system combines LLM-based explanation, adaptive tutoring, learner-state modeling, empathy-aware response generation, and monitoring-informed re-engagement to improve personalized learning.

## Key Features
- LLM-based concept explanation and adaptive tutoring
- Learner-state modeling for confusion, frustration, engagement, attention, and self-doubt
- Productive confusion vs harmful confusion handling
- Empathy-trigger logic for selective supportive intervention
- Step-by-step guidance, hints, worked examples, and simpler re-explanations
- Monitoring-informed support for attention drop, sleepiness, phone usage, and looking-away behavior
- Baseline vs emotion-enabled evaluation workflow
- Feedback analysis across clarity, confidence, empathy, frustration reduction, and monitoring acceptability

## Research Motivation
Conventional AI tutors often provide correct answers but may fail to recognize when a learner is confused, frustrated, disengaged, or losing confidence. This project explores how affective intelligence can help AI tutors respond more appropriately to a learner's emotional and cognitive state.

## Tech Stack
- Python
- LLM integration
- Prompt engineering
- Flask / backend APIs
- Emotion and affect modeling
- Survey / feedback analysis
- Monitoring and computer vision support
